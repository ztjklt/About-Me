# 软物理战斗 V3

2026-09-23，团结 2022.3.62t11。此轮按用户选定的「移动保持灵敏、身体柔软、抓取有双向拉力」实现；不是《人类一败涂地》完整物理沙盒。

## 操作与反馈

- 鼠标直接转镜头；战斗默认锁定光标。Esc 切换光标，B 背包/设置/失焦释放光标，返回战斗时过滤首帧鼠标跳变。观战仍可转镜头。镜头遇静态墙体会拉近；过近时隐藏遮住镜头的角色蒙皮，离开后恢复。
- WASD 各键分别识别 0.28 秒内双击，第二次按住奔跑；方向归一化。身体面向镜头前方，A/D 侧跑、S 倒跑。相反方向同时按下、菜单或失焦清除奔跑意图。
- J 轻击（0.10 秒命中），K 蓄力后松开重击（0.16 秒命中）；动作与伤害由同一权威时间线驱动。碰撞/按键不能重复结算同次攻击。
- G 抓人或公共物件，H 抓手持 Persona。0.20 秒伸手后验证接触，不立即吸附目标。
- 被抓时仍可反击、转镜头、受限移动，按住 Q 0.7 秒挣脱；触控界面有同等按住按钮与进度条。
- 抓取最多 2 秒，施抓者释放后冷却 1.5 秒，被抓者释放后免重抓 1 秒。NPC 使用相同规则并有反应延迟，不允许抓着连续轻击。
- E 吞噬/回收、1–5 切换装备。公共箱子/垃圾桶仍可手持挥击或重击投掷。

## 物理边界与数值

权威 Match 在 50 Hz 中先统一计算所有握持连接的弹簧/阻尼冲量，再积分双方移动并进行碰撞，避免玩家遍历顺序改变拉力。根部位移、击中、掉落、吞噬和胜负仅由服务器决定；没有客户端骨骼所有权切换。

首版人物抓取成功接触距离从草案的 1.7 米收紧至 1.12 米，以适配现有玩具人物的实际臂长；公共物件尝试范围为 1.25 米。前方锥角 120°、层高差上限 0.8 米；验证校园静态遮挡与掩体。接触使用简化权威代理，局部锚点记录在玩家根坐标系；表现层根据双方同一渲染时间的插值根姿态计算手部 IK。拉力、张力和角速度都有上限，超距/过载/命中/失衡/断线均释放。道具所有权不因抓取而改变。

角色使用 22 根变形骨骼和原有轻量碰撞代理。表现层采用逐关节角位置/角速度积分、有限驱动扭矩与阻尼，表达胸肩头臂的滞后、受击偏转及回弹；**不是 PhysX ConfigurableJoint 驱动的全身主动布娃娃**。这样保留了稳定根移动与服装/嘴部变形，不包含攀爬、悬挂或骨骼碰撞反向决定战斗结果。

## 接口与协作

- `Command.escapeHeld` 每份操作意图携带持续挣脱状态；过期输入在 0.35 秒后清除。
- `PublicPlayer` 增加真实根速度、动作 ID/类型/起始时间/变体、受击 ID/冲量、抓取锚点/张力和挣脱进度。
- `Snapshot` 增加协议版本 2、serverTick、抓取连接与结构化战斗事件；事件以 ID 去重为基础，最近事件滚动保留。持续动作状态用于时间线重建，客户端不通过动画事件制造伤害。
- Hello 保留原 Mirror 消息结构，版本标记置于已有 JSON 字段；双方版本不一致时明确拒绝。客户端、WebGL 和服务器应一起更新。
- 本地单人局与网络局使用相同 Match；外观、Persona API 与持久资产格式不变。
