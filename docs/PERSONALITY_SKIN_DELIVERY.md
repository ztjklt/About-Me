# 性格皮肤与游泳素材

角色衣橱增加性格 / MBTI 输入和「根据性格 AI 生成皮肤」。真实 DeepSeek 选择服装、配饰、图案和配色；客户端生成受控图案纹理。当前提供火焰、波纹、星点、叶片、电路、闪电、格纹、条纹八种图案。每次请求生成新的图案种子，预览后可调整、保存、撤销和重新载入。保存结果进入对局和服务器验证资料；不会更改 Persona、肤色、发色或表情。

这不是任意图片绘制或任意模型生成：AI 负责设计配置，程序负责可复现的纹理和已有角色服装。MBTI 是玩家指定的创作灵感。保留原有 DS / Claude 彩蛋皮肤入口。

自我介绍图片识别功能已移除：上传入口、浏览器文件选择、原生桥接和 `/introduction/recognize-image` 路由均已删除。大学校徽验证仍需要视觉能力，未随该入口移除。

增加原创代码建模的 `swimming-ring` 游泳圈：864 三角面，持久化材质、握点、缩略图和可装备目录条目。中文「我喜欢游泳」和英文 swimming 可以映射；否定「我不会游泳」不会误生成。当前使用 Cushion 的短暂缓冲机制，可装备、掉落、回收、吞噬；没有水中游泳模拟。

## 验收证据

- 后端 91 项测试通过，覆盖图案目录约束、未授权请求、失败不覆盖、预览与保存区分、读取和内部可信资料验证、游泳肯定与否定。
- 真实 DeepSeek 实测：热情又好奇 ENFP 生成 flame 图案约 1.30 秒；游泳 Persona 约 1.02 秒。耗时是本机该次请求结果，不能作为所有请求承诺。结果在 `artifacts/personality-skin-live/real-deepseek-result.json`。
- Web 游戏界面实际操作：输入介绍 → 游泳生成 → 衣橱 AI 预览 → 保存 → 重载 → 正背面 → 以当前角色开单人局。火焰衣服预览见 `artifacts/personality-skin-live/flame-preview.png`。
- 实际单人对局的 NPC 打落并吞噬游泳圈，结算正确记录其名称；见 `artifacts/personality-skin-live/swimming-swallowed.png`。这是本机单人游戏证据，并不证明真人多人体验或手机表现。
- 在首次 Web 试玩发现 prefab 的临时材质未序列化，已改为持久化 `.mat` 资源并增加打包断言，重新构建后游戏渲染正常。
- 客户端检查：八种图案不同且透明区正常、图案接入实际 SkinnedMesh、22 骨骼与四个吞噬变形保留、plain 还原、游泳圈圆孔和网格预算及材质资源。Mac 和 Web 均构建成功。

启动使用 `scripts/start-university-crests.command`，保持 1280×720 窗口。启动器会检查新皮肤能力与图片识别已关闭的服务标记，避免连接旧 API。
