# 记忆书桌 V2：四周陈设与暖色受光

## 为什么首版与概念图不同

概念图是生成的目标效果，其中包含柔和的间接光、接触阴影、木材纹理和背景虚化。首版只落地了空间轮廓与纯色几何：`CampusFlat` 的明暗区间较窄，背景没有桌面接触阴影，窗外只有天空色块，南侧只有铅笔与房间围合。这些差异实际存在，不能把概念图当成引擎最终画面。

V2 继续使用真实、可旋转的三维环境，补充完整南侧，并改善低成本实时渲染的材质和光照。没有调用 Tripo，也没有用概念图覆盖屏幕。

## 本次修改

- 南侧近景：叠放的薄荷速写本、粉色日记、书签、便签、信纸和夹子，延续原有横放铅笔。
- 南侧中景：奶黄色阅读灯与盆栽分列两边，桌子后方有独立座椅。桌面、桌腿、椅子和房间地面的高度关系已检查。
- 南侧远景：照片记忆板、纸胶带、小书架、相册和收纳盒。四个方向都有陈设，校园上方保持可读。
- 北侧：书堆移向窗户左侧，加入窗帘折面、树冠、远处建筑和渐变天空/柔和云层；相框旁增加植物。
- 新增 `MemoryDesk.shader`：粉彩受光、暖色反射、世界坐标木纹。共享材质仍为 8 个。
- 用实际静态网格投影生成 512×512 桌面柔影图，包含日光投影和接触遮蔽；运行时背景仍不投射实时阴影，不新增灯光。
- 游戏和编辑器预览共用北窗方向的日光、暖色光照及环境填充；校园保留实时阴影，阴影可见距离调整为 120。
- 底座倒角，桌面仍在 Y=-14，保留原有平台缺口；未增加碰撞、网络对象或可探索区域。

## 资源与检查

## 效果范围

此次补齐了南侧空间，以及首版缺失的木纹、接触阴影和暖色光照。实际画面依然是低面数游戏美术；概念图里的摄影级景深和复杂间接光没有等价实现。对战画面没有添加大幅背景虚化，以保持人物、预警与道具清晰。

首版性能记录在 `DESK_CAMPUS_DELIVERY.md`，不能将其直接作为 V2 的性能结论。

## V2 桌面运行验证

Apple M5 / macOS / 团结 2022.3.62t11，1600×900，开发版六角色离线场景，60 FPS 封顶。背景关闭/开启/开启/关闭（ABBA），每段等待 2 秒再记录 8 秒，共 1,892 帧。采集时没有运行 Unity 构建；原有用户客户端和本地服务器仍在运行，未强制关闭，因此不是整台机器的独占测试。

| 背景 | 平均帧间隔 | P95 范围 | 绘制调用/帧 | Unity 已分配内存 |
|---|---:|---:|---:|---:|
| 关闭 | 16.839 ms | 17.570–17.573 ms | 113 | 81.063 MB |
| 开启 | 16.810 ms | 17.572–17.574 ms | 121 | 81.067 MB |

背景增加 8 次绘制调用。帧间隔微小差异不代表开启背景更快，60 FPS 封顶也不能用于估算纯 GPU 成本。此次校园阴影方向、强度和可见距离已改变，场景总绘制调用不能直接与首版不同光照条件比较。两种状态均保留背景资源加载，内存差异不是资源完整加载成本。

原始数据：`artifacts/desk-campus/v2/mac/runtime-metrics.json`。9 张实际运行截图覆盖四方向、朝外视角、大手与观战，位于同目录。运行坠落检查通过；测试进程自行结束。

最新桌面包为 `builds/mac-background-v2/About Me.app`，原有已运行的旧版进程保持原样。旧进程不会因为工程或构建文件更新而自动获得新背景。

## WebGL 验证范围

桌面包成功构建后，共享工程出现另一项进行中的角色物理改动：`ActiveDollPhysics.cs` 引用了尚未接入 `Match` / `Player` 的 `BodyLanded`、`bodyMode` 等成员，导致主工程 WebGL 构建在脚本编译阶段停止。记录为 `artifacts/desk-campus/build-web-v2.log`，没有修改或删除该角色物理代码。

为验证背景自身的浏览器兼容性，使用此前可编译的客户端源码副本，将 V2 的背景生成器、运行脚本、全部预制体/网格/材质/柔影图、着色器及光照接入同步到独立验证工程。该副本只用于背景渲染验证，不代表其他任务最新角色功能的集成验收；背景资源目录与主工程逐文件比较一致。

独立工程：`artifacts/desk-campus/v2/verification/client`。独立 WebGL 输出：`artifacts/desk-campus/v2/verification/builds/web`。主站 `builds/web` 未用这个旧客户端基线覆盖。

独立 WebGL 构建成功，浏览器实际渲染检查通过，无浏览器 error/warn 日志。Chrome 152 / ANGLE Metal / Apple M5，1920×1080，共采样 1,907 帧；采样期间没有运行 Unity 构建，原有用户客户端与本地服务器继续运行。
