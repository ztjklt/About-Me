# 校园玩偶 V2：行走、奔跑与表情

本次在既有团结工程内实现，复用同一套 10 骨骼和 Tripo 基础模型；没有新增在线模型生成费用。现有校园、Persona、单人模式和菜单改动保留。

## 操作与权威规则

- W 首次按下并保持：普通行走，5.5 m/s；方向键和其他 WASD 方向保持普通行走。
- 两次 W 按下间隔不超过 0.28 秒：第二次保持期间奔跑，7.8 m/s。松开 W 恢复。
- 手机摇杆前向分量至少 0.85、幅度至少 0.90，持续 0.18 秒进入奔跑；前向分量低于 0.70 或幅度低于 0.78 退出。迟滞避免摇杆边界反复切换。
- 摇杆跟随手指，奔跑时显示“奔跑中”，分别处理移动与视角触点。
- 背包、设置、文本输入、切后台、失去焦点及受控状态清除奔跑输入。吞噬、回收、抓人和蓄力由权威逻辑限制奔跑。
- 命令只携带 run 意图，权威逻辑计算速度，约 0.18 秒渐变；对角输入归一化，超时 0.35 秒停输入。快照携带 running、airborne 和实际 locomotionSpeed。

## 动画

采用两套程序骨骼姿态，连续共享步态相位，并在约 0.16 秒内混合。不是把旧行走动画单纯加速。

| 初始姿态参数 | 行走 | 奔跑 |
| --- | --- | --- |
| 大腿摆幅 | ±27° | ±48° |
| 回收膝弯峰值 | 35° | 72° |
| 上臂摆幅 | ±22° | ±47° |
| 基础屈肘 | 12° | 68°，附加周期摆动 |
| 躯干起伏 | 0.035 m | 0.11 m |
| 躯干前倾 | 2° | 11° |

这些是原始步态参数，最终姿态叠加手臂避让、脚底高度修正和动作覆盖。头部抵消部分前倾；受击推移、空中和交互不会当成跑步。保留 20 Hz 快照插值。

手臂用固定长度 IK 保持掌心在躯干外侧；斜挎包附近抬高手部，肘部向外，避免袖子和手扫入包。吞噬保留独立伸臂、大嘴、仰头以及最后执行的送入口 IK。视觉鞋底修正不改变游戏碰撞或攻击距离。

## 表情与保存

六种表情：友好微笑、开心大笑、自信挑眉、慵懒半眯、惊讶睁眼、认真坚定。改变眉毛、眼睛、瞳孔和嘴形，附加眨眼；战斗紧张和大嘴暂时覆盖相应部位，随后恢复所选表情。

在“自我介绍预设”右侧直接选择，也可在“我的衣橱”中预览、切换及保存。保存属于独立外观配置；不生成或覆盖 Persona。旧外观缺少 expression 时默认友好微笑；AI 推荐服饰保留已选表情。真实账号随档案保存、样例随本机外观保存，联机快照同步。

## 验证与交付

- 服务端测试：20 项通过，包含六种表情往返保存、旧档案兼容、非法选项拒绝和 AI 推荐保留表情。
- 团结：既有 26 项规则与 11 项菜单/NPC 测试通过；新增输入时序、摇杆迟滞、速度上限、蓄力限制、断包停步及动作过渡验证。
- 六套外观在 30/60/120 FPS 下测试走→跑→吞噬→恢复；检查掌心与前臂对胸部/斜挎包的简化包围体净距、嘴手净距和鞋底高度。最小身体/包净距约 2.0 cm；最小吞噬手嘴净距约 4.8 cm。这里是给定测试轨迹与包围体的结果，不等于对任意接触情形的全网格碰撞证明。
- 六个真实客户端进程通过本机 WebSocket 联机回归，六种表情保持一致，结算正常。
- 六角色校园动作实测：Apple M5、1600×900，平均约 59.2 FPS，P95 帧耗时约 17.6 ms，最大关节分离约 2.66 cm。该结果来自桌面动作探针；尚未进行手机真机或公网联机性能验收。
- 运行界面实拍已检查，人物介绍页六个表情选项可见，衣橱保留完整外观编辑。

交付文件位于 `artifacts/characters-v2/`：

- `About Me Movement.app`：macOS 试玩程序。
- `walk-run-eat.mp4`：引擎实渲染的正面/侧面行走、奔跑、停步和吞噬过渡。
- `walk-run.gif`：行走到奔跑的简短预览。
- `expressions.png`：六种表情对照。
- `introduction-expressions.png`：人物介绍页实拍。
- `release.log`、`runtime-motion-metrics.json`：构建/规则验证与性能证据。
