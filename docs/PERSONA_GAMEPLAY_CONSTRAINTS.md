# Persona 道具玩法约束（目录扩充轮）

依据：`docs/STATUS.md`、`shared/catalog.json`、`shared/persona-prop-candidates.json`、`server/app.py`、`client/Assets/AboutMe/Runtime/GameModel.cs` 与 `SoftCombat.cs`，2026-09-23。以下“现状”是代码审读，不代表真人平衡试玩。

## 目录准入

1. 每件道具只有一个生效的 `templateId`，从当前 12 类模板中选。名称、颜色、模型和视觉隐喻不改变伤害、射程、碰撞体积或掉落概率；同模板道具同规则。
2. `shared/persona-prop-candidates.json` 的 `modifier` 目前只是策划意向。`PersonaAsset` 没有该字段，服务器生成结果也不带该字段。需要弹跳、牵引、缓冲、掩体行为时，直接将已发布道具映射到 `Ricochet`、`Tether`、`Cushion`、`Barricade` 模板；不要把 `Projectile + Ricochet` 等组合写成已生效机制。
3. 生成服务只接受发布目录的 `(templateId, visualId)` 配对，且每个生成结果必须对应介绍原文中可定位的一条事实。学校信息统一映射带校名的 `Disc / school-disc`；不凭职业、学校或模型外观推导额外技能。
4. 一位玩家的道具数量本身就是生命余量。新增目录项不能提供永久成长、吞噬收益、免掉落、自动回收或让对方直接失去 Persona 的能力；击中造成韧性与失衡，真正掉落仍由统一权威规则处理。

## 模板行为与边界

现状的单一「使用道具」内部沿用重击路径，基础间隔 1.05 秒，命中前摇 0.16 秒；普通近战为 2.8 米、基础 48 × 1.3 = 62.4 韧性伤害（当前 `UseItem` 固定满蓄力）。远程效果使用同一基础伤害，以下只列差异。玩家输入规则详见 `docs/ATTACK_INPUT_RULE.md`。模板“反制”指本轮可向玩家承诺的玩法或需要先由 Unity 补齐的准入条件。

| 模板 | 现状机制和数值 | 可用反制与目录文案边界 |
| --- | --- | --- |
| `Melee` | 2.8 米正面重击，1.05 秒间隔 | 拉开距离、侧移、在命中前打断；不宣称额外连击或穿墙。 |
| `HeavyWeapon` | 近战伤害 ×1.25、推力 ×1.2，间隔 1.35 秒 | 利用较长收招反击；不要为个别大模型再叠伤害或射程。 |
| `Projectile` | 12 米/秒，最多存在 2 秒，命中后消失 | 横移躲弹、命中前打断使用者；当前飞行物没有通用墙面碰撞，不能宣传“可被墙挡住”。 |
| `Disc` | 14 米/秒，最多 2 秒，最后 0.8 秒朝主人方向返回；每目标至多命中一次 | 躲开飞行路线；不宣称回程可再次命中同一目标。 |
| `Ricochet` | 12 米/秒，最多 3 秒，边界/静态阻挡可反弹，计数 2 | 观察反弹方向避让；不叠加第二套 `Projectile` 效果。 |
| `Deployable` | 飞出后减速落地，存在 8 秒；同一目标至多受击一次 | 绕开落点；当前不支持主动拆除，文案不能说“可击碎”。 |
| `Summon` | 7 秒自动追最近敌人，移动 6 米/秒，对同一目标命中间隔 1.4 秒 | 跑开或先打断召唤者；当前不可击杀且无视视线追踪，扩大投放前须补可见反制。 |
| `Utility` | 5 米正面重击，28 韧性伤害、推力 2，间隔 5 秒 | 趁较长间隔逼近；名称可表现闪光/声波，但当前没有致盲、治疗或控制状态。 |
| `SpecialAbility` | 4.5 米范围重击，推力 15，间隔 7 秒；当前不检查朝向 | 留在范围外、趁间隔反击；必须以范围冲击表述，不能为眼镜/雨靴等分别承诺透视、跳跃增益。 |
| `Tether` | 前方约 6 米牵引，目标短硬直约 0.28 秒，间隔 1.35 秒，无伤害 | 横移脱离前方目标锥；当前目标搜索未查墙面遮挡，不能宣称掩体防牵引。 |
| `Cushion` | 1.15 秒防护窗，抵消一次重击并反弹，间隔 1.4 秒 | 诱发后抓取，或等防护窗结束；不依赖另一种攻击输入。 |
| `Barricade` | 前方放置半径 0.85 米掩体，7 秒、2 点耐久，间隔 2 秒 | 绕行或重击拆除；不宣称永久封路。 |

## 通用对局约束

- 装备道具优先掉落；掉落物保留到原主人回收或他人吞噬。回收 1.5 秒、吞噬 2.5 秒，均可被打断；吞噬者不获得道具能力。掉出地图按统一规则掉 1 件，周期大手掉 1 件。
- 展示阶段 5 秒不可争抢。战斗第 150/300 秒大手，第 450 秒结算；到时先比吞噬数，再比剩余 Persona。目录文案和试玩脚本采用这套已实现节奏。
- 用户实际测试后决定只保留「使用道具」一种攻击。现有 `UseItem` 每次固定触发内部满蓄力重击路径；所有伤害型模板可能承受更高击倒风险，需真人试玩复核，不恢复旧 PRD 的轻重双输入。
- 目录扩充先保持当前模板数值，不为每件道具设私有加成或新冷却。需要新机制时，先由玩法定义范围、持续时间、命中次数、冷却、反制与验收，再由 Unity 修改权威 Match 和客户端表现，最后才发布到生成目录。

## 扩充的验收条件与待办

每件新增道具记录：`visualId`、名称、介绍原文可支持的来源类型、唯一 `templateId`、可观察重击行为、具体反制、模型/授权状态。发布后应能由生成服务接受对应 `(templateId, visualId)`、在客户端持有/掉落/回收/吞噬，并且与同模板样本道具行为一致。证据需分别标注目录/API 测试、自动对局、真人试玩；目前没有真人平衡数据。

Unity 主责的后续实现门槛：把已提交整合版的轻重双输入收敛为单一「使用道具」；为远程效果补统一静态遮挡与命中可读性；给 `Summon` 和 `Deployable` 可见的驱散/拆除方式或限制其同时存量；为 `Tether` 补视线检查；防止短冷却 `Barricade`/长驻效果无限堆叠。完成前，Persona 主责可做模型和目录映射，但不要在道具说明中承诺这些未实现的反制。
