# 选择页静态背景交付

| 页面 | 背景资源 |
| --- | --- |
| 自我介绍 / 预设 | 现有 `StartMenu2D/background.png`，页面已有静态铺底 |
| 单人 / 多人选择、大厅 | 现有 `StartMenu2D/background.png`，叠一层轻纸色以保证文字可读 |
| 设置、衣橱 | 新增 `SelectionBackgrounds/studio-wardrobe.png`，叠一层轻纸色 |

新增插画以仓库现有开场校园图为风格参考生成；没有使用外部图片素材。Unity 将它作为 Sprite 导入。背景图和纸色蒙层位于全屏 Canvas 中的卡片下方，按窗口比例居中裁切，均不拦截点击；1600 × 900 安全区画板只承载卡片和入口，避免 4:3 与超宽屏的拼接缝或漏出场景。现有四入口主菜单、战斗 HUD、背包与结果页的操作没有修改。

无对局的菜单页关闭 ToyWorld 动态预览；战斗时全屏背景停用，背包继续保留战场上下文。设置或衣橱关闭后恢复此前场景，不修改战斗相机的位置、朝向或视口。
