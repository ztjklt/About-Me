# 选择页静态背景交付

| 页面 | 背景资源 |
| --- | --- |
| 自我介绍 / 预设 | 现有 `StartMenu2D/background.png`，页面已有静态铺底 |
| 单人 / 多人选择、大厅 | 现有 `StartMenu2D/background.png`，叠一层轻纸色以保证文字可读 |

新增插画以仓库现有开场校园图为风格参考生成；没有使用外部图片素材。Unity 将它作为 16:9 Sprite 导入并放在页面卡片下方，图片和纸色蒙层都不拦截点击。现有四入口主菜单、战斗 HUD、背包与结果页没有修改。

本补丁只负责 1600 × 900 页面区域内的静态背景。客户端整合任务负责超出该区域的全屏铺底，以及进入这些选择页时关闭 ToyWorld 的动态预览。合并后需以实际运行画面验收 16:9 与窄屏、宽屏尺寸；本补丁尚未单独进行最终运行截图验收。
