# UI 交互动效交付：衣橱视角

本轮将用户提供的两份交互设计材料提炼为项目 skill：`.agents/skills/about-me-ui-interaction/`。模式表用于今后的菜单、角色编辑与 HUD 选型；它不是要求一次加入全部效果。

## 本轮选型

衣橱的“正面 / 侧面 / 背面”是稳定的三项视角选择，原界面切换镜头后缺少持续可见的选中状态。因此采用 **Liquid Tab Indicator**：薄荷色背景位于固定的文字和按钮下方，移动时前缘先到、后缘收拢。按钮本体、命中区域和角色预览区域不移动。它沿用玩具贴纸配色，无额外插件或位图。

| 状态 | 行为 |
|---|---|
| 打开衣橱 | 镜头和指示背景立即设为正面 |
| 选择侧面或背面 | 镜头当帧切换；指示背景从当前可见位置移动到新按钮 |
| 快速连续选择 | 新目标接管现有运动，最终停在最后一次选择 |
| 重新打开 | 回到正面，不残留关闭前的过渡 |
| 减少动态 | 指示背景直接定位，仍保留颜色和文字的选中提示 |

可调运动值在 `UILiquidTabIndicator.cs`：前缘/后缘约 `0.10 / 0.19` 秒的阻尼时间，以及最多增加 `64` UI 单位的拉伸宽度。它们是当前界面的设计参数。

## 验证与范围

- 在隔离的团结 2022.3.62t11 工程中生成 macOS 开发构建；构建成功，随构建运行的 26 项权威规则及菜单 / NPC 规则检查通过。隔离构建避免改写本 worktree 原有未提交资源。
- 1600×900 macOS 开发构建截图已检查：[正面](ui-interaction/wardrobe-front.png)、[侧面](ui-interaction/wardrobe-side.png)。侧面图通过隔离构建中的临时回调冒烟检查生成；回调触发后指示背景最终位于侧面按钮，角色预览也转到侧面。
- 桌面自动化未能稳定向该 Unity 窗口传递鼠标点击，因此本轮没有把回调冒烟检查当作真实鼠标或触控验收。键盘实际操作、横屏手机触控和微信真机仍需 QA 在对应设备上检查。
