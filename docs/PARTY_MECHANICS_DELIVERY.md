# 第一批 10 种爆风机制

2026-10-04。本批新增 6 件项目原创模型：橡果、网络路由器、闹钟、板球拍、弹性史莱姆罐、锥形瓶。连同前批 29 件，累计新增 **35 件实际模型**，运行目录 **95 件**。320 候选还剩 286 件模型未制作。本批实现 **10 种新机制**，100 项目标还剩 90 项；候选清单不会被当作已实现数量。

| 机制 | 道具 | 触发与反制 |
|---|---|---|
| 接触爆风 | 派对礼炮 | 接触人、墙或地面爆开；使用者也会受到范围伤害 |
| 延时爆风 | 橡果 | 2.4 秒公开倒计时；可抓起并扔回去 |
| 遥控爆风 | 网络路由器 | 再次使用引爆；可搬走或击打两次拆除，8 秒未引爆就消失 |
| 感应爆风 | 闹钟 | 地面玩家进圈后 0.6 秒引爆；离开圈会取消，空中经过不触发 |
| 扇形爆风 | 板球拍 | 前方 60° 冲击并使使用者后退；侧后方安全 |
| 黏附爆风 | 史莱姆罐 | 命中后跟随目标，1.6 秒爆开；按住 Q / 挣脱按钮 0.7 秒撕掉 |
| 吸入再爆开 | 锥形瓶 | 落地后先吸入 0.5 秒再推出；可以移动脱离或拆除 |
| 接力爆风 | 寿司卷 | 最多放置 3 个，4 米内按顺序接力；搬走中间节点可打断，未被接力的后续节点安全过期 |
| 三点爆风 | 爆米花桶 | 三个不同落点逐个预警、逐个爆开；累计冲力不超过单次爆风预算 |
| 地面冲击环 | 法槌 | 1.2 秒向外扩散，一名玩家只命中一次；可跳过薄环，不跨不同高度楼层 |

这是虚拟玩具效果：原创代码粒子、地面预警圈、公开倒计时与道具模型。权威服务器决定命中、击退、吸入、倒地和掉落。AI 只匹配目录道具；不会产生可执行机制或任意逻辑。机制数据在 `shared/persona-mechanics.json`，客户端副本完全一致，实现为 `PartyMechanics.cs` 与 `PartyMechanicVisual.cs`。

背包和对局底部显示机制说明及反制方式，对局显示使用冷却。部署物不是额外生命；真正 Persona 的回收、掉落、抢夺和吞噬仍由同一实例计算。部署来源被吞噬、所有者被淘汰或比赛结束时清理装置和持有人状态。已掉落而未吞噬的来源允许短暂已部署效果按原计时结束。爆风统一通过原有 Hit / 倒地 / 起身保护流程。

## 验证范围

- 后端 129 项通过，新增模型各自的事实/否定事实匹配、原始配方唯一、机制目录绑定和客户端副本检查。
- Unity 19 个权威规则场景通过，覆盖十种触发、倒计时公开、反制、墙体与不同楼层、跳跃、冷却、防重复、起身保护、掉落数量和部署清理。
- Unity Play Mode **20 个真实物理场景**通过，10 种机制各测完整韧性与耗尽韧性，使用真实 15 刚体角色。完整韧性下最终位移约 0.38–1.45 米，耗尽后约 1.22–3.62 米；最大测得速度低于 13.1 m/s。耗尽各场景只掉落一次且 Persona 总生命数量保持一致。此证据是可复现物理场景，不是多人真人趣味性评价。
- Mac 与 Web 构建包含最新 UI，窗口 1280×720；没有开启全屏。34 件原创组装模型的材质、独特几何、1500 三角面预算、握点、吞噬锚和缩略图检查通过。
- 真实 DeepSeek 输入“网络工程和路由器、化学实验、寿司”，一次约 1.28 秒得到三个正确模型、三个 ready 词条。证据在 `artifacts/party-mechanics-live/real-deepseek-mechanics.json`，不构成所有请求的耗时承诺。
- Web 实际填写生成、同义词绿色结果、三件新模型在 NPC 对局中掉落吞噬并正确结算；遥控装置的模型、公开预警与冷却在实际 Web 对局中可见。重跑两客户端进程、模拟 150ms 延迟及重连通过，380 / 473 个物理快照、两个外观和一次吞噬结算。此联机回归使用既有样例道具，证明客户端兼容，不代表每种新机制的远程联机验收。
- 同义词误报已修正：网络工程、路由器可共同指向同一件已生成路由器；未制作的小提琴仍为红色，旧保存结果读取及再次生成可修正，避免只改新请求。
- 真人平衡和趣味性、触屏设备及公网尚待验证，不能以这些自动化结果替代。
