# 攻击输入最终规则：单一「使用道具」

## 决策与依据

用户在实际测试后明确决定：「在实际测试中 我发现轻击压根没啥用 我们就保留一种攻击方式就是道具使用吧」。此决定取代 `docs/PRD.md` 原有轻击、蓄力重击、空手轻击设计。旧 PRD 是产品历史，不能当作当前验收目标。

已提交整合版 `8e12edf` 仍有 J 轻击、按住 K 蓄力重击及两个触控攻击按钮；当前本工作树的未提交实现则已有 F / 触控「使用道具」一路，并由 `UseItem` 触发模板效果。两者代表不同代码状态；本文件定义统一目标，不把任一工作树的完成度当作产品决定。

## 玩家可观察规则

1. 战斗只有一个攻击操作，名称为「使用道具」。键鼠默认 F，触控为单个「使用道具」按钮；按下一次请求一次已装备 Persona 的模板效果，不按住蓄力，不提供轻击和重击选择。
2. 道具各有不同的唯一效果：近战打击、投掷、牵引、防护、召唤等仍按现有受控模板执行。同模板道具使用同一规则；不按道具名称添加私有攻击。先沿用当前 `UseItem` 的满蓄力重击路径和模板数值，后续根据真人试玩单独调平衡，不把“满蓄力”暴露为玩家操作。
3. 手里没有 Persona 也没有公共道具时，按「使用道具」不产生攻击。空手仍可移动、跳跃、抓人和拉扯、抓手持 Persona、争夺位置、回收自己的掉落物或吞噬他人的掉落物。抓取可打断对方回收/吞噬；不承诺独立的空手轻击。
4. 手持公共道具时，同一「使用道具」操作将其投出。Persona 掉落、回收、吞噬、韧性、淘汰和结算沿用现行权威规则。
5. NPC 与真人使用同一单一攻击规则。客户端的键鼠、触控、提示文字、教程和自动对局脚本都应使用同一个 `use_item` 意图；服务端不应留可由旧客户端或伪造输入触发的 `light`、`charge`、`heavy` 隐藏攻击通道。

## 当前风险

当前单键实现将内部重击充能固定为 1.0，伤害型模板命中时都会带击倒标志。用户决定的是输入简化，尚未给出新的平衡数值；首轮真人试玩应重点记录击倒频率、掉落率、空手反制是否足够，以及 2–6 人抢夺/吞噬节奏，再决定是否调整模板参数。
