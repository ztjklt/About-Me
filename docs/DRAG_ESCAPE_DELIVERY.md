# 抓拖与挣脱第一轮改良

一次抓取继续锁持，再按 G / 抓取按钮松手。窗口从两秒增加到三秒；抓者步行系数从 0.45 到 0.68，被抓者从 0.55 到 0.72；双方仍不能在抓链中冲刺。锚点每秒最多转 210 度，入抓以 0.12 秒平滑渐入。真实物理拉力保留 110 / 12 / 90 上限，持续高张力会松手，反向移动可削弱拉力 20%。

实际布娃娃中，被抓角色暂时解除脚底世界锚的固定，并降低水平脚步支撑和水平站立纠偏；竖直支撑保留。首次实测发现固定脚步抵消拉力，因此没有靠提高最大力解决。拉扯使用现有接触骨骼和等反向力，不瞬移，不附赠抛力。站起、断线、攻击与受击仍会正确解除抓链。

按住 Q / 触控挣脱 0.7 秒完成；短松手 0.12 秒保留进度，随后按 0.35 秒的衰减速度归零。松手不增长进度，输入失联超过 0.35 秒直接清空；完成后免重抓 1.1 秒。HUD 显示抓者松手提示及被抓者百分比。

验证：34 项权威规则测试通过，增加短松手、长松手衰减、失联清空、平滑转向和抓时步行不能冲刺。实际 Unity 物理测试使用完整 15 个刚体与接触骨骼，覆盖直拉、90 度转弯、有限速度及持续 Q。布娃娃回归通过倒地、起身、跳跃、墙、拖拽后起身解除、阶梯、六人堆叠和掉落保护。

本机测试中，0.9 秒半输入直拉，目标移动约 0.35 米，抓者约 0.73 米；突然 90 度转弯会因高张力较早断链，目标约 0.21 米。它们是自动物理测量，不代表真人手感或乐趣已经验收。1–2 米持续拖距、绕柱、边缘、第三人解围、触控拖离按钮与 150ms 网络延迟仍需继续测。
