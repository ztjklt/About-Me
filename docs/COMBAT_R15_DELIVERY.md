# 完整 R15：两击近战与高伤害接触场地

目标：让有效命中更快造成击飞和 Persona 掉落，继承完整 R14 的嘴型、五到七字透明头顶气泡、开场准备调侃及全部既有整合功能。

主责：本任务依用户指令维护玩法数值、客户端及 Mac 权威共用的 Match；独立工作树 `combat-impact-r15`、分支 `codex/combat-impact-r15`。未修改或提交其他角色原工作树源码，未派子代理。

## 玩家可观察规则

| 类型 | 新行为 |
|---|---|
| 普通近战（书、球棒、短剑等） | F 发动真正轻击，前摇0.1秒、间隔0.5秒、范围仍2.8米，每击60稳定度；连续两次有效命中使满稳定度目标击飞并掉落一件。长时间间隔仍允许原有稳定度恢复。 |
| 重型武器 | 基础重击90，内部满蓄力及重型倍率后146.25；一次有效命中满稳定度目标掉落。 |
| 基础范围能力 | 内部满蓄力117伤害；一次有效命中满稳定度目标掉落。 |
| 干扰类 | 前方5米、100伤害，原5秒冷却保留；一次有效命中掉落。解决低伤害被2.5秒后稳定度恢复抵消的问题。 |
| 球／圆盘／反弹投掷／基础盆栽投掷／动物 | 保留命中耗尽稳定度并掉落；抛出的是真实原资产，仍须回收或可被对手吞噬。 |
| 公共箱桶投掷 | 从12提高到100伤害，有效命中即可掉落。 |
| 爆风、冲击环、上挑、落地震荡、热水袋、跑步绊线、扫杆 | 各有效判定100伤害；落地震荡移除旧30伤害上限。原预警、方向、高度、墙、跳跃与反制条件保留。 |
| 喷火／热情文字 | 两次各60，共120；完整两次有效命中掉落。 |
| 路障／湿迹／浅沙／胶场／凝结冰面 | 对手在地面接触后击倒掉落一次；每个目标每次部署最多一次，保护期接触不消耗触发，跳过安全。路障由实际阻挡的移动位置触发。来源拥有者不会被自己的这组场地击倒。 |

轻击可以拆除路障与公共机关，仍按两次击打计数。致掉落的自定义冲量保证至少7水平、3向上后再应用现有反制与衰减，避免高伤害却只有轻微踉跄；倒地、起身保护和单次生命掉落仍走原生产流程。工具、搬运、协作与防守用途不凭空变成伤害技能。机制提示及新增中文／English说明保持一致。
