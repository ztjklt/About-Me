## 用户明确的 UI / UE 决定

1. 首次启动、重复启动、对局后返回均直接呈现现有暖色教室、耳机男孩和四个入口的主菜单。
2. 移除“按任意键进入”“点击进入”等二次门槛；旧左上 About Me、左下框、右侧选项列表的主菜单弃用，不能经返回、缓存状态或失败分支再次进入。
3. 所有操作按钮采用短按钮或紧凑图标按钮，不使用横贯面板的长条动作按钮。输入框、物品列表、滚动区和进度条不因这条要求被错误裁短。
4. 触碰有轻快的“bulin”感：按压、释放、选中、不可用状态可感知；轻压缩与短回弹等反馈克制，不遮挡、不妨碍连续操作，尊重减少动态效果与音量设置。
5. 删除非必要说明性文字，避免界面杂乱；保留必要标签、即时错误、权限、数量和交互进度。额外帮助按需展开。
6. 背包物品识别、选择、装备态、空态和五快捷栏清晰；滚轮/拖动、选择与滚动不会互相误触。
7. 触控热区易按，移动、镜头、道具及持续挣脱可组合操作，多指不互抢，离开按钮/取消/失焦时不会粘键。
8. 延续原作主菜单视觉；中央人物位置、旋转、缩放保持稳定，可保留眨眼，按钮和外围图层提供适量动效。
