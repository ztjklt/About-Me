# 最新 UI 按钮审查与修复（2026-10-04）

本轮独立执行，没有派子代理。采用最新版四气泡首页和现有 Persona 编辑页，1280×720 窗口验证；没有开启全屏。

## 修复结果

| 问题 | 现在的行为 |
| --- | --- |
| 本地启动器的练习角色被本机权威服务拒绝 | 匹配的本机服务开启样例模式；生产服务默认限制保持原规则 |
| 登录过期、只有缓存 Persona 时仍尝试联机 | 提示重新生成并转到介绍页，保留缓存用于单人练习 |
| 性格能力试验台没有菜单入口 | 单人选择页增加入口，六种效果、MBTI、释放和返回可操作 |
| 试验台选中效果和自动演示没有准确反馈 | 当前选择高亮，自动演示显示开启/关闭，再次进入恢复初始演示 |
| 背包标题因高度不足完全不显示 | 标题完整显示随身数量和剩余 Persona |
| 分享房间码成功、失败和无剪贴板支持没有反馈 | 显示复制成功或手动复制房间码的提示 |
| Web 结算截图缺少可见保存结果 | 帧结束后截图，展示真实结算 PNG 预览、下载入口和手动保存说明 |
| 录音失败或权限延迟会留下错误按钮状态 | 恢复录音按钮；停止早于授权完成时关闭后来取得的音轨 |
| 正常连接时重连按钮无反馈 | 显示当前连接正常，或正在连接 |
| 衣橱保存、AI 推荐等提示被弹窗遮住 | 提示保持在最上层，可读出保存成功或样例限制 |
| 离开后重新创建房间会卡在正在连接 | 等待旧 WebSocket 关闭后自动连接，等待及失败有明确提示 |

## 实际点击覆盖

| 区域 | 实际验证 |
| --- | --- |
| 首页与设置 | 四个首页入口；设置五项循环选项、保存和关闭 |
| 自我介绍预设 | 新建、保存、选择、删除本轮新建空草稿、返回；空介绍生成校验、彩蛋校验；六个表情、四个颜色 |
| 衣橱 | 十三项左右切换共 26 个按钮；三种视角；普通皮肤与两种锁定皮肤的样例限制；推荐的样例提示、保存、撤销、重新载入、关闭 |
| 单人 | 当前角色开始、练习角色开始、NPC 对局实际结算、再来一局、退出、返回主菜单 |
| 性格试验台 | 六种效果、全部 MBTI 轮换、单次释放、自动开关与返回 |
| 多人 | 本机两个独立 Web 客户端创建、加入、准备、开始；分享复制成功；缺少微信配置的二维码提示；离开大厅和退出对局 |
| 对战与背包 | 六个触控按钮触发对应命令，五个快捷装备栏、打开和关闭背包、装备与置顶；置顶后快捷栏顺序实际变化 |

点击以实际页面状态、截图及可选 BUTTON_AUDIT_CLICK/战斗命令日志交叉核对，未通过注入游戏状态或伪造按钮回调代替点击。单纯点击日志不等于网络成功。

## 构建与证据范围

- Mac 和 WebGL 匹配构建通过；Mac 包 codesign 深层严格检查通过，原生客户端窗口启动正常。
- Unity 检查：按钮恢复/弹窗提示层级、15 项菜单、31 项规则及菜单/NPC 套件、校徽双面覆盖与主色、特效粒子边界。

- 原生 Mac 的自动化点击未被 Unity 正确接收，因此实际逐按钮证据来自同一最新版源码的 WebGL；没有声称原生 Mac 已逐按钮手动验收。
- 微信真实二维码、微信相册保存、真实麦克风/ASR、个人图片上传识别、锁定彩蛋真实解锁、真人公网联机未纳入本轮成功验收。已验证可用的缺配置/样例限制提示。

- 真实大学联网生成证据仍见已有 Persona 交付，本轮没有重复发送真实生成请求。

用户项目中的证据在 `artifacts/button-audit/`：`ui-clicks.json`、`final-ui-clicks.json`、`wardrobe-feedback.jpg`、`result-screenshot-preview.jpg`、`reconnect-feedback.jpg`、`reentered-lobby.jpg`。构建日志为实现工作区 `artifacts/ButtonReconnectBuilds.log`。
